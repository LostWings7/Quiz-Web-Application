How to Prepare Your File

Each row in your spreadsheet is one question. Use these recommended columns (you'll map them on the next screen):

Column NamePurposeRequired?
question_textThe question body textRequired
question_imageFilename (from ZIP) or URL for the question's imageOptional
option_1First answer option textRequired
option_1_imageImage for first answer option (filename or URL)Optional
option_2, option_2_imageSecond answer option text + imageOptional
option_3, option_3_imageThird answer option text + imageOptional
option_4, option_4_imageFourth answer option text + imageOptional
correct_optionWhich option is correct — enter 1, 2, 3, or 4Required*
subtopicSubtopic name (created automatically if new)Optional
orderDisplay order numberOptional
* Required for CSV files. For Excel (.xlsx), you can instead highlight the correct answer cell in any colour — it is detected automatically.

Excel (.xlsx) — Best Option

Highlight the correct answer cell in any colour. This is the easiest way — no need for a correct_option column.

  • One row = one question
  • Put image filenames (e.g. q1.png) in image columns
  • Bundle images together in a ZIP (see below)

CSV — Simple Option

Add a correct_option column with values 1, 2, 3, or 4 to mark the correct answer.

  • No colour support in CSV
  • Use URLs in image columns for online images
  • Or ZIP with image files for local images

ZIP — For Local Images

Put your spreadsheet and all image files into one ZIP archive:

  • questions.zip
      ├─ questions.csv (or .xlsx)
      ├─ q1.png
      ├─ q2.png
      └─ opt_a.png
  • Reference images by filename in the image columns
  • Images can be PNG, JPG, JPEG, GIF, or WebP

URLs — For Online Images

Put a direct image URL in any image column:

  • e.g. https://example.com/img/q1.png
  • Works for question_image and all option_image columns
  • Images are downloaded and stored on import
  • URL must point directly to an image file
